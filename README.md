# Hearthline Property Desk

A frontend demonstration for residential property owners and leasing teams. It brings rent collection, leasing, property details, and maintenance requests into a single operations workspace.

This project uses fictional properties, residents, and lease information. It is not connected to a backend or a real property management system.

## Local development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```
